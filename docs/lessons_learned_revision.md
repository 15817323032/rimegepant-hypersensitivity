## 二、六大根因（按危害排序）

### A. 统计定义没在动笔前锁定（最深层，返工成本最高）

分箱边界、显著性术语、主/敏感性分析的边界都是**写作时临场决定**的，审稿人一挑就翻：

- TTO 分箱把 0 天和 1 天并成 "≤1 day (67%)"——直到第五轮才发现 0 天占 59.6%、1 天只占 7.8%，**结论含义完全不同**（同日发生 vs 次日发生）
- robust = ≥2/4 algorithms 而非 4/4（第一轮就翻）
- "significant" → 补 q_BH → 统一为 "nominal (BH q=0.056)" 拉锯三轮
- 2025Q3 label revision 从主分析挪到敏感性分析
- TTO 特征是 post-onset 的 → ML 泄漏，被迫补 noTTO 模型

**教训：分箱边界、术语、敏感性分析必须在 protocol 阶段写成硬定义并冻结，动笔前照抄，不临场发明。**

### B. 单一真源缺失 → 多副本漂移（占意见数约 1/4）

- Table 3 的真源是 `all_tables.xlsx` 的 sheet，不是同名 CSV——只改 CSV，包内表格仍旧值（第五轮踩坑）
- 图件从 `results_label_change/` 旧渲染目录复制，`figures_r/` 根本没进打包管道 → Fig2 裁切两次复发（第四轮根因）
- 同一数字散布在 Abstract/Results/Discussion/Table/Figure/README/cover letter/Key Points：改一处漏三处（"67%" 四处、"eight primary analyses" 两处、新标题三处同步）

**教训：数字只允许出现在 results 文件一处；文档引用由脚本注入或改后全局 grep 清点出现次数是否与预期一致；渲染产物只有一个目录，打包脚本只从那里取。**

### C. 措辞强度超出证据等级（审稿人最爱挑，约 1/3）

- day-level TTO 日期 → 不能断言 immediate-type 机制（两次被挑）
- 剂型信号写 rimegepant-associated，不归因 ODT 制剂/辅料
- SYK markedly weaker、BTK inconclusive——不许合并写成 "no support"
- 纯数据挖掘结论只写关联与因果提示（用户既定铁律）
- 伦理：写 "does not constitute human-subjects research"，**不写 exempt**（exempt 是 IRB 的决定，不是作者的）
- 封面信不声称期刊的 allowance（450 词）是既成事实

**教训：每个定性词（significant / associated / suggests / inconclusive / hypothesis-generating）在写的时候就问一句"这句话的证据等级撑得起吗"；数据挖掘稿默认降一档。**

### D. 格式转换管道静默失败（不报错、不提示，只有肉眼发现）

- md→docx：单元格字面竖线截断行、内嵌管道表整段漏转、两表攒一张错位、浮点全精度裸奔
- R `paste()` 里 `\n` 位置错 → 图底注超长/截断/重复片段
- python-docx `t.cell()` O(n²)：437×24 大表 44 分钟
- PDF 提取因文件名与预期不符直接失败

**教训：转换"跑通"≠"转对"。所有表格渲染走同一个出口函数 + 自动化校验（表数/行列数/结尾标点/裸 `|` 段落为 0），任何新转换逻辑先在小样本上验证再跑全量。**

### E. 视觉问题只能像素级目检（脚本校验的盲区）

- Fig2 右缘裁切（两次）、Fig3 底注重复片段、Fig4 面板标题挤碰、S2 虚线框标题溢出
- 裁出 caption band 单独看，比整图缩略可靠得多

**教训：投稿前对每张图做一次"裁带目检"（标题带、底注带、面板间隙逐个放大看）；图的字号/宽度问题先看信息是否已在图注中冗余，优先删字而非加宽。**

### F. 标题/编号是全局变量，改动必须触发同步清单

- S1 标题没跟新主标题（第五轮）
- READUS checklist 4b/8a 引 "Fig. 4" 实为 Supplementary Figure S2
- S1.3 残留 "ODT-specific oral cluster" 措辞
- 标题改动要同步：正文标题页、标题页脚本、cover letter、review packet、README

**教训：改标题 = 至少查 8 处（manuscript 标题页 / build 脚本 TITLE / cover letter / README / checklist / 图注 / 表题 / 引用该标题的 checklist 条目）；改图表编号同理。**

## 四、下篇文章的写作前检查单（新增，按顺序执行）

1. **冻结统计定义**：分箱边界（半开区间）、主/次要终点、敏感性分析边界、显著性术语（nominal/q 值）写进 protocol，动笔后不临场改。
2. **建术语注册表**：列出全文允许使用的定性词及其使用条件；正文逐节核对。
3. **单一真源**：文档中不写裸数字——从 results 文件引用或脚本注入；必须手写时记录出现位置清单。
4. **图件单向管道**：渲染 → 唯一目录 → 打包脚本复制；删掉/不引用任何旧渲染路径。
5. **每轮修订固定动作**：改完 → 闸门全绿 → 全局 grep 所有改动数字/标题的残留 → 裁带目检全部图。
6. **多文档同步清单**：标题、Key Points、cover letter、README、checklist、表题、图注、补充材料编号。
7. **打包后终检**：presubmit + 打开 docx 肉眼过每张表每张图（防静默转换错误）。
